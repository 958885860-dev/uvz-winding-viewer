# UVZ winding viewer

Interactive winding route viewer for U, V and W/Z coils. Published with GitHub Pages.

The page includes its own visualization library and route data. It supports progress scrubbing, forward/reverse playback, orthographic 3D navigation and an unfolded cylinder view.

This is a geometry and winding order viewer. It does not certify material bend limits or installation on the actual holder. STEP files are not included.
